## Objective
Deploy a simple static website using GitHub Pages.

## Tools Used
* Git Bash
* GitHub
* GitHub Pages
* HTML
* CSS

## Project Description
I created a simple static website using HTML and CSS. The website contains a welcome page and a custom design. The project was uploaded to a GitHub repository and deployed using GitHub Pages.

## Files Included
* index.html
* style.css
* screenshot.png

## Steps Performed
1. Created the project folder.
2. Developed the website using HTML and CSS.
3. Initialized a Git repository.
4. Added and committed project files.
5. Created a GitHub repository.
6. Pushed the code to GitHub.
7. Enabled GitHub Pages from the repository settings.
8. Verified the live website deployment.
